## API Reference
- [List organizations](https://developer.augusthealth.com/reference/listorganizationsv1.md): List organizations visible to the current user.
- [List facilities](https://developer.augusthealth.com/reference/listfacilitiesv1-1.md): List facilities visible to the current user in a given organization.
- [List rooms for a facility](https://developer.augusthealth.com/reference/listroomsv1.md): Returns all active rooms for the specified facility, including configured beds and market rates. Optionally filter by effective date.
- [Get admission history for a resident](https://developer.augusthealth.com/reference/getadmissionhistoryv1.md): Returns the complete admission and discharge history for a specific resident
- [Get admission history for all residents in a facility](https://developer.augusthealth.com/reference/getfacilityadmissionhistoryv1.md): Returns paginated admission and discharge history for all residents in the specified facility
- [Get bed assignment history for all residents in a facility](https://developer.augusthealth.com/reference/getfacilitybedassignmenthistoryv1.md): Returns paginated bed assignment history for all residents in the specified facility
- [List bed assignment history for a resident](https://developer.augusthealth.com/reference/listbedassignmentsv1.md): Returns the complete bed assignment history for a specific resident
- [Get statement PDF](https://developer.augusthealth.com/reference/getstatementpdfv1.md): Retrieve an issued statement PDF for a resident.
- [Get resident billing summary](https://developer.augusthealth.com/reference/getbillingsummaryv1.md): Retrieve billing summary for a single resident including: - Resident identification and status - Physical and financial move-in/move-out dates - Latest issued statement details - Current balance - Payer contacts (contacts marked as "Payment of Care")
- [List facility billing summaries](https://developer.augusthealth.com/reference/listfacilitybillingsummariesv1.md): Retrieve paginated billing summaries for all residents in a facility including: - Resident identification and status - Physical and financial move-in/move-out dates - Latest issued statement details - Current balance - Payer contacts (contacts marked as "Payment of Care")  Results can be filtered by resident status using the `residentStatus` query parameter.
- [Record deposit](https://developer.augusthealth.com/reference/recorddepositv1.md): Integration partners submit collected payments as a consolidated deposit.  **Authentication**: Bearer token (JWT) required with `BILLING_PAYMENTS_CREATE` permission.  **Idempotency**: If the same `externalDepositId` is resubmitted, returns the existing deposit without creating duplicates. The retry must contain the exact same set of payments (by `externalTransactionId`); mismatched payments return a `400` error.  **Atomicity**: All payments in the batch succeed or none do. If any `personId` is invalid, the entire batch is rejected.  **Payment Types**: - `PAYMENT`: Standard payment (amount must be positive) - `PAYMENT_RETURN`: Returned payment, e.g., NSF (amount must be negative) - `REFUND`: Refunded payment (amount must be negative)  If `paymentType` is omitted, it defaults to `PAYMENT`.  **Cash Account Code**: The `cashAccountCode` field controls which GL cash account is assigned to the deposit for accounting export purposes. - If the facility has GL cash accounts configured: `cashAccountCode` is **required** and must match a configured code. - If no GL cash accounts are configured: `cashAccountCode` **must not** be sent.
- [Search statements](https://developer.augusthealth.com/reference/searchstatementsv1.md): Search for issued private pay statements by billing period. Provide either `billingPeriod` (YYYY-MM) or both `startDate` and `endDate`, but not both.
- [List resident billing transactions](https://developer.augusthealth.com/reference/listresidentbillingtransactionsv1.md): Retrieve paginated billing transactions (payments and charges) for a resident. Includes both active and deleted transactions.  Use the `updatedAfter` parameter to pull only transactions that have been created or modified since your last query.  Each transaction has an `idType` of either `PAYMENT` or `BILLING_CHARGE`. Payment-specific fields (`paymentMethod`, `paymentSource`, `merchantFeeCents`) are null for charges. Charge-specific fields (`invoiceId`, `feeName`, `rateCents`, `quantity`, `taxCents`, `medicaidProgramShortName`) are null for payments.
- [Get Census Person](https://developer.augusthealth.com/reference/getcensuspersonv1.md): Get limited demographic information for a specific person within a facility
- [List Census](https://developer.augusthealth.com/reference/listcensusv1.md): Lists limited demographic information for people within a facility
- [Create an incident](https://developer.augusthealth.com/reference/createincidentv1.md)
- [Get an incident](https://developer.augusthealth.com/reference/getincidentv1.md)
- [List incidents and notes for a facility](https://developer.augusthealth.com/reference/listfacilityincidentsv1.md): Returns a paginated list of all incidents and notes for all residents at a facility. Results are sorted by alert status (alerts first), then by creation time (newest first).
- [List incidents and notes for a person](https://developer.augusthealth.com/reference/listpersonincidentsv1.md): Returns a paginated list of incidents and notes for a specific person. Results are sorted by alert status (alerts first), then by creation time (newest first).
- [Update an incident](https://developer.augusthealth.com/reference/updateincidentv1.md)
- [List facility med passes](https://developer.augusthealth.com/reference/listmedpassesv1.md): List med passes in a given facility.
- [List all medication administrations for all residents of a facility](https://developer.augusthealth.com/reference/listfacilitymedicationadministrationsv1.md): Returns a paginated list of all medication administrations for all residents at a facility.
- [List all medication administrations for a person](https://developer.augusthealth.com/reference/listpersonmedicationadministrationsv1.md): Returns a paginated list of all medication administrations for a specific person.
- [List all medication orders for all residents of a facility](https://developer.augusthealth.com/reference/listfacilitymedicationordersv1.md): Returns a paginated list of all medication orders for all residents at a facility. Results are sorted by order ID (ascending).
- [List all medication orders for a person](https://developer.augusthealth.com/reference/listpersonmedicationordersv1.md): Returns a paginated list of all medication orders for a specific person. Results are sorted by order ID (ascending).
- [Create Person](https://developer.augusthealth.com/reference/createpersonv1-1.md): Create a resident within a specific facility
- [Get Person](https://developer.augusthealth.com/reference/getpersonv1-1.md): Get a specific resident within a facility
- [Get Person Profile Photo](https://developer.augusthealth.com/reference/getpersonprofilephotov1.md): Returns the profile photo for a resident as a binary image (168x168). Supports ETag-based caching via the If-None-Match header.
- [List People](https://developer.augusthealth.com/reference/listpeoplev1-1.md): Lists all residents within a facility
- [Get latest Resident Biography](https://developer.augusthealth.com/reference/getlatestresidentbiographyv1.md)
- [Extract structured resident biography from text](https://developer.augusthealth.com/reference/extractresidentbiographyv1.md)
- [Create Resident Biography](https://developer.augusthealth.com/reference/createresidentbiographyv1.md)
- [Get the latest admission agreement](https://developer.augusthealth.com/reference/getlatestadmissionagreementv1.md): Returns the resident's latest completed admission agreement, regardless of customType. Agreements in any other status are skipped, so a resident with a draft in progress still resolves to their current completed agreement. Archived agreements are only retrievable through the by-ID endpoint.
- [Get an admission agreement by ID](https://developer.augusthealth.com/reference/getadmissionagreementv1.md): Returns a specific admission agreement by snapshot ID. The snapshot must belong to the specified resident and have the admission agreement data type; requests for snapshots of any other data type return 404.
- [Download an admission agreement PDF](https://developer.augusthealth.com/reference/getadmissionagreementpdfv1.md): Returns the PDF for a specific admission agreement snapshot. The snapshot must belong to the specified resident and have the admission agreement data type; requests for snapshots of any other data type return 404.
- [Get the latest assessment](https://developer.augusthealth.com/reference/getlatestassessmentv1.md): Returns the most recent completed/finalized internal assessment for a person. External/imported assessments are excluded from this endpoint.
- [Get an assessment by ID](https://developer.augusthealth.com/reference/getassessmentv1.md): Returns a specific assessment by snapshot ID. The snapshot must belong to the specified person and be an assessment type.
- [Create contact](https://developer.augusthealth.com/reference/createcontactv1-1.md): Create a new contact for a person.
- [Get contact](https://developer.augusthealth.com/reference/getcontactv1-1.md): Get details for a specific contact.
- [List contacts](https://developer.augusthealth.com/reference/listcontactsv1-1.md): List contacts for person.
- [Sets the specified Contact as the Responsible Person for a given Person.](https://developer.augusthealth.com/reference/setresponsiblepersonv1-1.md)
- [List routine administrations for a person](https://developer.augusthealth.com/reference/listroutineadministrationsv1.md)
- [Bulk chart routine administrations for a person](https://developer.augusthealth.com/reference/bulkchartroutineadministrationsv1.md)
- [List tasks](https://developer.augusthealth.com/reference/listtasksv1.md): List tasks for a specific person.
- [List visitor log entries for a resident](https://developer.augusthealth.com/reference/listvisitorlogsv1.md): Returns a paginated list of non-deleted visitor log entries for the resident, sorted by sign-in time descending.
- [Create a visitor log entry](https://developer.augusthealth.com/reference/createvisitorlogv1.md): Records a sign-in for a visitor of a resident. The request may optionally include sign-out information if the visit has already ended.
- [Soft-delete a visitor log entry](https://developer.augusthealth.com/reference/deletevisitorlogv1.md): Marks a visitor log entry as deleted. Soft-deleted entries are excluded from list responses.
- [Create a vital measurement](https://developer.augusthealth.com/reference/createvitalv1.md): Records a new vital measurement for a resident. The request must include at least one vital type in the panel (e.g., weight, temperature, blood pressure). This endpoint is intended for on-demand measurements from sensor devices and API partners.
- [Get a vital measurement](https://developer.augusthealth.com/reference/getvitalv1.md): Retrieves a single vital measurement by ID for a resident.
- [Update a vital measurement](https://developer.augusthealth.com/reference/updatevitalv1.md): Update selected fields of a vital measurement.
- [List vital measurements](https://developer.augusthealth.com/reference/listvitalsv1.md): Returns a paginated list of vital measurements for a resident. Results are sorted by recorded time (newest first).
- [List facility shifts](https://developer.augusthealth.com/reference/listshiftsv1.md): List shifts in a given facility.
- [List users](https://developer.augusthealth.com/reference/listusersv1.md): Lists all users in an organization who are a staff member.
- [Create an API token for programmatic access for August Health API](https://developer.augusthealth.com/reference/createtokenv1.md)
- [Get access to the webhooks application portal (if one is configured)](https://developer.augusthealth.com/reference/createwebhooksportalaccessurlv1.md)
